MagicMtn Provider for [Modal](https://modal.com): Run agents in remote Linux sandboxes on Modal.

This private provider is available exclusively through MagicMtn's cloud offering. MagicMtn manages its deployment, credentials, and sandbox images. It is not published to the provider registry or available for users to install themselves.
